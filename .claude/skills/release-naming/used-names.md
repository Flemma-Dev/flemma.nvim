# Incipit — the Flemma release codex

> _incipit_ — Latin "here begins"; the opening words of a manuscript, often the most ornamented line on the page.

Codenames assigned to Flemma **minor** releases. One single-word typographic / bookmaking term per release, chosen to fit that release's headline work — see the [`release-naming`](SKILL.md) skill for how picks are made. Append here whenever a release is named. **Never reuse a name on this list.**
