Externalized conversation messages, tool definition strings, and the full user-facing surface into gettext PO catalogues, split by audience: `po/flemma-harness.po` holds model-facing strings (conversation text, tool descriptions — English-only prompt surface), `po/flemma.po` holds user-facing UI strings (the translatable surface, all keys namespaced `ui.*`). Covers notifications (usage, rejection popup, tool actions, :Flemma commands, send-pipeline guards, provider switch/initialize, diagnostics, build-prompt failures, autopilot, presets, hooks, secrets, config validation, sandbox, migration, response truncation, max-tokens clamping, request/cURL errors), keymap descriptions, and user-triggered template diagnostics (file references, includes, expression errors). Adds gettext plural support — `msgid_plural`/`msgstr[N]` selected by a compiled `Plural-Forms` expression (EN/FR/RU/PL), fixing e.g. "1 orphaned job resolved" vs "N orphaned jobs resolved". A `make qa` gate (`lint-messages.sh`) validates key resolution, call-site↔template variables, `#. Variables:` comments, no pure-formatting entries, and newline-only joins between translations. Rendered strings are unchanged (still English by default); keys stay unique across the files, enforced when the catalogue loads.
